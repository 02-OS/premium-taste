03 · Zero-Dependency Setup

Wire it into your project or MCP client in 30 seconds.

Runs cleanly on stock Python 3 with zero npm or pip packages. Bundle the taste catalog + CLI scripts locally or connect the stdio MCP server directly.

  1. Name the job in one sentence starting with a verb.
  2. Pick 1 direction & 1 reference from taste/ or via pick_direction MCP.
  3. Verify deterministically with audit.py (static) and critique_url.py (headless Chromium).
bash · copies .premium-taste/, scripts/, and .mcp.json 
curl -fsSL https://raw.githubusercontent.com/02-OS/premium-taste/master/install.sh | bash -s -- . --agent all --mcp

Or dry-run locally without modifying files: python3 scripts/install.py /path/to/app --agent all --mcp --dry-run

.mcp.json (Claude Code · Cursor · Codex CLI) 
{
  "mcpServers": {
    "premium-taste": {
      "command": "python3",
      "args": [".premium-taste/scripts/mcp_server.py"]
    }
  }
}

Tools exposed: pick_direction, get_reference, get_tokens, audit_ui.

CI & localhost checks 
python3 scripts/audit.py src/
python3 scripts/critique_url.py http://localhost:4173/
python3 scripts/check_catalog.py
